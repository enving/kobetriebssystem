# Plugins (extern, zusätzlich)
Zusätzliche Plugins von außen (z. B. Konnektoren, Fachwerkzeuge), die das Betriebssystem ergänzen. Vor Aufnahme prüfen: Herkunft, Rechte, Datenabfluss; Freigabe nur per PR und über den Marketplace der Firma (siehe `installation/`).
Das Betriebssystem selbst als Plugin bauen und verteilen: `installation/`.
