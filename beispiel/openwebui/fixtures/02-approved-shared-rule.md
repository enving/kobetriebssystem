# Freigegebene allgemeine Regel (fiktiver Teststand)

Wenn Zuständigkeit oder Datum in einer Quelle unklar ist, wird die Lücke als offen markiert. Keine Person oder kein Datum wird aus dem Kontext ergänzt. Jede Aussage im Ergebnis verweist auf die genaue Quelle.

Version: 1.0 (synthetischer Prüffall)
