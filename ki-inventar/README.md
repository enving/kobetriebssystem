# KI-Inventar

Wer Agenten selbst baut, ist nach der KI-Verordnung für jeden davon Anbieter
([Herleitung](../docs/architektur/anbieterrolle-und-pflichtenabdeckung-2026-11-09.md)). Darum bekommt jeder Agent hier
eine Datei nach [`_rollenpruefung-vorlage.md`](_rollenpruefung-vorlage.md):

- **wann:** vor dem ersten Einsatz, bei jeder Zweckänderung, bei Wechsel von Modell oder Plattform
- **wer:** die benannte Aufsichtsperson des Agenten füllt aus, die Rechts- und Compliance-Stelle gibt frei
- **wie:** als Pull Request; die Freigabe ist das Mergen

Ein ausgefülltes, erfundenes Beispiel: [`beispiel/ki-inventar/wissensassistent.md`](../beispiel/ki-inventar/wissensassistent.md).

Das Inventar ist ein Baustein für ISO/IEC 42001 und PRD-Lücke L18. Es ist kein Konformitätsnachweis und keine
Rechtsberatung.
